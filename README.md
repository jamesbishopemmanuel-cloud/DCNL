# DCNL Website

Responsive business website for DCNL (Destinyt Company Nigeria Limited).

## Included
- Responsive mobile/desktop design
- Home, About, Services, Industries and Contact sections
- Phone call buttons
- WhatsApp quote/enquiry form
- DCNL business information from the supplied reference
- Supplied reference image in `assets/`

## Run locally
Open `index.html` in a browser.

## Deploy on GitHub Pages
1. Create a GitHub repository.
2. Upload all files from this folder.
3. Go to Settings -> Pages.
4. Select the main branch and root folder.
5. Save.

The site is static, so no backend is required for the first version.
